Testing the use of AGENTS.md and Claude Code to build NISAR tools for snow products

MCS_domain.kml = area of interest at Mores Creek Summit
testNISARdownload.py = initial simple download script
nisar_downloader.py = function to grab NISAR data using asf_search
download_MCS_NISAR.py = calls nisar_downloader.py to get NISAR data over MCS from Feb 1-25, 2026
