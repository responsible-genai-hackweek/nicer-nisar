# Mores Creek Summit Study Area Boundary

Boundary shapefile/GeoJSON for the Mores Creek Summit LiDAR domain, used as a potential Area of Interest (AOI) for NISAR-based snow depth analysis.

## Files

- [`Mores_lidar_domain.zip`](./Mores_lidar_domain.zip) — Shapefile (EPSG:6340, NAD83(2011) / UTM Zone 11N)
- [`mores_boundary_utm.geojson`](./mores_boundary_utm.geojson) — GeoJSON (EPSG:32611, WGS84 / UTM Zone 11N)

## NISAR Details

- **Tracks:** 77, 149 (Ascending, Frame 24)
- **Dates of interest:** 2025-12-09, 2025-12-21, 2026-01-07, 2026-01-19
