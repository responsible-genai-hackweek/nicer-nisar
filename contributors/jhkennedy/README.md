I've started asking a set of basic questions to different AIs to get a feel for how well they understand NISAR and could help new users. 

## Questions

> [!TIP]
> For Claude, you can export chat session history using the `/export` command. Interestingly, sometimes if you export a `.txt` file, you'll get all the terminal output for the duration of the session, but if you export a `.md` file, you'll get just the questions and responses. 

### Glaicers
 
Conversations are saved in the `glaciers/` directory. 


#### How do?

Prompt:
> How do I get glacier velocity estimates from NISAR?


Responses:
 - `galaciers/asis/how-do*` - responses from models as they are currently, with no enhancements (skills, tools, RAGs, MCPs, etc.). I've also provided a high-level summary of the responses and, particularly, what's missing from them in `glaciers/README.md`.
